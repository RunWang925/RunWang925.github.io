### 文件路径可用占位符说明

| payload       | 描述                   |
| ------------- | ---------------------- |
| {year}        | 当前日期 - 年          |
| {month}       | 当前日期 - 月          |
| {day}         | 当前日期 - 日          |
| {fullName}    | 完整文件名（含扩展名） |
| {fileName}    | 文件名（不含扩展名）   |
| {extName}     | 扩展名（不含.）        |
| {md5}         | 图片 MD5 计算值        |
| {sha1}        | 图片 SHA1 计算值       |
| {sha256}      | 图片 SHA256 计算值     |
| {timestamp}   | Unix 时间戳            |
| {timestampMS} | Unix 时间戳（毫秒）    |
|               |                        |

例如，如果我这里设置的上传路径为{year}/{month}/{day}/{fullName}，则图片将会按照日期存储在对应的文件夹中。

关于缤纷云证书上传和证书自动续期参考我前面写的文章

例如我已经完成自定义域名绑定，自定义域名为https://bitiful.814925.xyz
