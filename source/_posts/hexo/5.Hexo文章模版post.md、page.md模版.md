# **新建文章**

我们先来写一篇文章 或者多写几篇后面我们才能看到效果

hexo new 加上文章的名称（我这里就叫这是我的第一篇博客文章）

```Bash
hexo new 这是我的第一篇博客文章
```

![img](https://bitiful.814925.xyz/2024/11/15/202411151027083.png)

成功后可以在source-_posts里面看到一个.md的文件。这个时候也可以保存然后预览一下效果。

预览发现几个问题：

![img](https://bitiful.814925.xyz/2024/11/15/202411151027975.png)

1.文章没有封面。2.顶部没有背景，白色的背景和字体有些冲突。看不清楚。

下面我来修改一下模板在试试

# 修改默认模板效果

以后新建文章的时候每一篇文章的顶部属性就会添加这些字段，这些属性字段包含的东西太多了直接看注释吧

大部分可能都用不到 ，就算有用不到的字段留着也没有关系 

`/scaffolds`目录下有几个模版文件，其中

- **post.md**：新建博文模版
- **page.md**：新建标签页模版

# **post.md模版，仅供参考**

```Bash
---
title: {{ title }} #【必需】页面标题
date: {{ date }} #【必需】页面创建日期
updated: #【可选】页面更新日期
tags: #【可选】文章标签
categories: #【可选】文章分类
keywords: #【可选】文章关键字
description: #【可选】文章描述
top: # 1 置顶
top_img: #【可选】文章顶部图片
comments: #【可选】显示文章评论模块(默认 true)
cover: https://random.ruom.top/img.php?category=原神 #【可选】文章缩略图(如果没有设置 top_img,文章页顶部将显示缩略图，可设为 false/图片地址/留空)
toc: #【可选】显示文章 TOC(默认为设置中 toc 的 enable 配置)
toc_number: #【可选】显示 toc_number(默认为设置中 toc 的 number 配置)
toc_style_simple: #【可选】显示 toc 简洁模式
copyright: #【可选】显示文章版权模块(默认为设置中 post_copyright 的 enable 配置)
copyright_author: #【可选】文章版权模块的文章作者
copyright_author_href: #【可选】文章版权模块的文章作者链接
copyright_url: #【可选】文章版权模块的文章作者链接
copyright_info: #【可选】文章版权模块的版权声明文字
mathjax: #【可选】显示 mathjax(当设置 mathjax 的 per_page: false 时，才需要配置，默认 false)
katex: #【可选】显示 katex(当设置 katex 的 per_page: false 时，才需要配置，默认 false)
aplayer: #【可选】在需要的页面加载 aplayer 的 js 和 css,请参考文章下面的音乐 配置
highlight_shrink: #【可选】配置代码框是否展开(true/false)(默认为设置中 highlight_shrink 的配置)
aside: #【可选】显示侧边栏 (默认 true)
swiper_index: 10 #【可选】首页轮播图配置 index 索引，数字越小越靠前
top_group_index: 10 #【可选】首页右侧卡片组配置, 数字越小越靠前
ai: #【可选】文章ai摘要
background: "#fff" #【可选】文章主色，必须是16进制颜色且有6位，不可缩减，例如#ffffff 不可写成#fff
---
```

特别说明一个参数：12行代码 cover: 这个参数的用途就是当你文章 如果没有设置 top_img就是封面的时候就显示这个图片 这里可以替换成自己喜欢的图片或者api进行随机

我这使用的是 梦爱吃鱼大佬的图片API https://random.ruom.top/后期我可能也会写一个自己的图床API

https://random.ruom.top/img.php?category=原神 随机返回大佬图床里面原神图片

# **page.md模版，仅供参考**

这个模板用处不大，只是留着注释后面明白每个字段用途干啥

```Bash
---
title: {{ title }} #【必需】页面标题
date: {{ date }} #【必需】页面创建日期
type: #【必需】标签、分类、关于、音乐馆、友情链接、相册、相册详情、朋友圈、即刻页面需要配置
updated: #【可选】页面更新日期
comments: #【可选】显示页面评论模块(默认 true)
description: #【可选】页面描述
keywords: #【可选】页面关键字
top_img: https://random.ruom.top/img.php?category=原神 #【可选】页面顶部图片
mathjax: #【可选】显示 mathjax(当设置 mathjax 的 per_page: false 时，才需要配置，默认 false)
katex: #【可选】显示 katex(当设置 katex 的 per_page: false 时，才需要配置，默认 false)
aside: #【可选】显示侧边栏 (默认 true)
aplayer: #【可选】在需要的页面加载 aplayer 的 js 和 css,请参考文章下面的音乐 配置
highlight_shrink: #【可选】配置代码框是否展开(true/false)(默认为设置中 highlight_shrink 的配置)
top_single_background: #【可选】部分页面的顶部模块背景图片
---
```

# 新建文章看效果(**post.md)**

hexo new 加上文章的名称（修改模板以后得一篇博客文章）

```SQL
hexo new 修改模板以后得一篇博客文章
```
