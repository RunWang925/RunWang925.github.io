  4. 「Branch」：选择「gh-pages」→ 「/(root)」→ 点击「Save」
  5. 保存后，页面顶部显示：Your site is ready to be published at https://RunWang925.github.io/
  6. 访问验证（注意延迟）
  • 生效时间：配置后需等待 1-5 分钟（GitHub 同步静态文件）
  • 访问地址：https://RunWang925.github.io（固定域名，无需修改）
  • 成功标志：显示与本地http://localhost:4000一致的页面

七、历史错误复盘与避坑指南

  1. 分支名不匹配（最常见错误）
  • 错误提示：fatal: the requested upstream branch 'origin/main' does not exist
  • 原因：本地分支是 master，远程是 main
  • 解决方案：git branch -m master main（修改本地分支名）
  1. 依赖冲突（ESM 错误）
  • 错误提示：Error [ERR_REQUIRE_ESM]: require() of ES Module ... strip-ansi/index.js
  • 原因：strip-ansi 新版本与 Hexo 不兼容
  • 解决方案：在package.json添加resolutions: {"strip-ansi": "6.0.1"}，并执行npm install
  1. 权限错误（403 Permission denied）
  • 错误提示：remote: Permission to RunWang925/... denied to github-actions[bot]
  • 原因：默认 GITHUB_TOKEN 权限不足
  • 解决方案：配置 PAT 令牌，在工作流中使用secrets.HEXO_DEPLOY_TOKEN
  1. 推送冲突（failed to push some refs）
  • 错误提示：error: failed to push some refs to 'https://github.com/...'
  • 原因：GitHub 仓库有本地没有的文件（如 README）
  • 解决方案：git pull --rebase origin main（同步远程文件后再推送）
  1. 本地预览空白页
  • 原因：缓存或生成文件错误
  • 解决方案：hexo clean && hexo generate && hexo s（清空→生成→预览）
